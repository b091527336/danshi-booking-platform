# 丹媞創網多服務訂閱平台｜產品藍圖 v0.1

狀態：草案，待業主驗收。此文件不代表功能已開發或部署。

## 產品定位
丹媞創網提供單一會員帳號、服務目錄、訂閱管理與各服務模組。第一個模組為 DBP（Danshi Booking Platform），後續可擴充 SEO、廣告與 CRM 等服務。

## 優先順序
1. 保持現有 ANASA 六據點的 Google Reserve / TableSit 預約與同步不中斷。
2. DBP 客戶後台：登入、租戶資料隔離、據點切換、預約清單、同步狀態。
3. 共用會員中心：組織、使用者、角色與服務授權。
4. 訂閱產品目錄：方案、價格、訂單、訂閱狀態；先以測試資料驗證。
5. 金流與自動開通：選定金流並完成付款回調、安全性、發票及退款規則後才上線。
6. 其他服務模組：DSEO、DAds、DCRM，依實際需求逐步啟用。

## 架構原則
- Laravel / MySQL / Bootstrap 5 為既定技術方向，實際版本以現有專案與部署環境驗證。
- 以 tenant_id 隔離客戶資料，Organization 隸屬 Tenant。
- DBP 透過 TableSit API Adapter 串接；保留替換供應商能力。
- 付款狀態與服務開通由伺服器驗證，不能只依前端成功頁。
- API 憑證只存安全環境變數或祕密管理服務，禁止提交 Git。
- 不把第三方服務商的品牌、成本或條款錯誤描述給客戶。

## 第一個驗收關卡
- 可確認現有程式架構與執行環境。
- 可在測試環境登入，僅看到授權客戶的據點及預約。
- 可驗證 TableSit 同步的成功、失敗與去重機制。
- 未經驗證不得宣稱已上線或具備自動訂閱功能。
